---
title: Deal Code Not Working
description: What to do if your AppSumo code won’t redeem.
---

## Issue
- Code says "invalid" or "already used"
- Redeem page error

## Quick Fixes

<Steps>
  <Step title="Check code accuracy">
    ````
    Carefully copy and paste the code from your AppSumo account, avoiding spaces.
    ````
  </Step>
  <Step title="Confirm deal is active">
    ````
    Some deals have redemption deadlines—check the product details.
    ````
  </Step>
  <Step title="Contact support">
    ````
    Email support@appsumo.com with the code and screenshot for fast help.
    ````
  </Step>
</Steps>
